# Sentiment Analysis of Twitter Reviews Using NLP and Naive Bayes

## Overview
This project performs sentiment analysis on Twitter reviews using:

- NLP
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Streamlit

## Dataset
Twitter Sentiment Analysis Dataset from Kaggle.

## Technologies Used

- Python
- Pandas
- NLTK
- Scikit-Learn
- Streamlit

## Run

pip install -r requirements.txt

streamlit run app.py
